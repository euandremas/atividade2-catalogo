# 🛒 Catálogo de Produtos em React

Projeto desenvolvido como evolução das atividades da disciplina de Front-End Development, consolidando conceitos de React, estado, eventos e integração com API.

---

## 📌 Sobre o Projeto

Esta aplicação simula um **catálogo de produtos dinâmico**, permitindo:

- Cadastro de produtos
- Remoção de produtos
- Listagem dinâmica
- Filtros por nome e categoria
- Controle de produtos em promoção
- Cálculo automático do valor total

O projeto foi evoluído ao longo das atividades (Unidades 2, 3 e 4), incorporando novos conceitos a cada etapa.

## 🔌 Integração com API

Foi utilizado o **JSON Server (`db.json`)** para simular uma API REST.

### Métodos utilizados:

- `GET` → Listar produtos
- `POST` → Cadastrar produto
- `DELETE` → Remover produto

Essa abordagem aproxima o projeto de um cenário real de desenvolvimento.

---

## 💾 Persistência de Dados

- 📦 Produtos → persistidos via **JSON Server**
- 🎨 Tema (dark/light) → persistido via **LocalStorage**

## ▶️ Como Executar o Projeto

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/euandremas/atividade2-catalogo.git
```

### 2️⃣ Acessar a pasta

```bash
cd atividade2-catalogo
```

### 3️⃣ Instalar dependências

```bash
npm install
```

### 4️⃣ Rodar a API (JSON Server)

```bash
npm run api
```

### 5️⃣ Rodar o projeto React

```bash
npm start
```

---

## ⚠️ Observações

- Recomenda-se utilizar **Node.js versão 18.x** para evitar incompatibilidades com `react-scripts`
- O JSON Server deve estar em execução para que a aplicação funcione corretamente
